上游审计：2026-11-23 ​

对照 2026-11-17 的审计快照检查 17 个参考仓库的分支提交、近期更新 issues 与未关闭问题。此记录区分协议证据和已验证的 TuneWeave 行为，不把上游提交标题视为兼容性证明。

上游新变化TuneWeave 处理
libresoda 搜索更新配置签名器时改用 PC 综合搜索未替换现有分类搜索。匿名签名实测：晴天、Moonhalo 的综合接口均返回 6 首、无后续游标；现有分类接口已验证每页 20 首及跨页。综合接口的结果不能直接当作完整分类目录。
libresoda 下载报告更新续传结果附带实际使用的流信息属于文件下载器的交付契约，不移植其本地暂存文件与续传实现。TuneWeave 的流和下载结果已有实际音质、格式及试听信息；调用端独立下载工作不在本次范围。
music-lib 网易云画像补齐给缺少客户端字段的 Cookie 补充 os/appverTuneWeave 的 EAPI 加密请求 header 与 HTTP Cookie 已按所选协议配置客户端画像；不全局替换为上游的另一组版本值，避免影响已有 Android 音质配置及会话。
PopDownloader 播放回退track_v2 空响应时读取 SEO 与 media-player不直接采用。TuneWeave 已有 SEO 公共来源及账号授权媒体解析；新回退仍须验证账号归属、实际试听范围和媒体身份，不能仅按最长时长或 90% 时长阈值宣称完整授权。
api-enhanced腾讯云部署说明及 CI 更新没有新增音源协议修复需要移植。
UnblockNeteaseMusicXEAPI 代理 hook、B站异常响应处理、依赖更新TuneWeave 已有独立 XEAPI 与 B站业务错误/备用地址处理，不移植代理 hook、会员展示修改和 Node 依赖。
musicdl移除 Deezer/Qobuz 的第三方源不涉及 TuneWeave 当前支持的平台。
Lotus-ReFactor米游社、游戏签到、抽卡与凭据更新本次变更未涉及 TuneWeave 参考的网易云协议。

QQMusicApi、KuGouMusicApi、miguMusic-api-enhanced、kuwoMusicApi、BBDown、bilibili-api-collect、listen1-api、qishuiMusicAnalysis、SodaDownloader、qishui-decrypt 在本次对照区间没有新提交。

Issues ​

  • api-enhanced #305：Linux 多用户共享 /tmp/xeapi_public_key 导致权限错误。TuneWeave 公钥状态为进程内缓存，不使用这个共享临时路径。
  • api-enhanced #300：取流返回 -460 风控仍是未关闭问题，不作为已修复功能发布。TuneWeave 保留上游业务失败诊断。
  • musicdl #105：汽水加密 M4A 无法播放仍未关闭。TuneWeave 已有独立授权媒体解析及解密，不据此放宽密钥、媒体身份或容器校验。
  • QQMusicApi #309 的 CDN 问题已关闭，但该仓库没有相对基线的新提交；不把关闭状态当作新增补丁。
  • 酷狗 20028 / v_type=38 等设备验证问题仍在未关闭列表中，没有本次可直接移植的新修复。

本次审计没有发现应直接替换 TuneWeave 现有实现的已验证上游修复；保留 beta.4 已合入的功能与修复，另行完成发布前全仓回归。
